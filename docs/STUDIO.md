# Local Studio / OpenRouter

Verification date: 2026-10-12. Docker and a local Studio service were unavailable in the implementation container. These setup instructions follow official source; actual integration remains unverified.

1. On a Docker-capable machine, install the GenLayer CLI and initialize a local Studio (`genlayer init --headless --numValidators 5`, then `genlayer up`). Use a compatible CLI/Studio release family: stable testing uses gltest 0.29.2; Consensus v0.6 needs matching RC tooling and fee profiles. Do not silently mix those versions.
2. Open http://localhost:8080 → Settings → Inference Providers → New Config. Official Studio ships provider `openrouter`, plugin `openai-compatible`, and plugin config `{"api_key_env_var":"OPENROUTERAPIKEY","api_url":"https://openrouter.ai/api"}`. Choose a supported model and create validators using that provider.
3. Make the owner's `OPENROUTER_API_KEY` available to the Studio backend as `OPENROUTERAPIKEY` in the backend/container process environment. The two names are different. Preserve it only in process memory or an outside-repository secret file managed by the owner; do not modify the repository `.env`, print the value, or put it into contract source. Provider defaults alone do not supply the key to a container.
4. Run mocked integration with `ISSUE_BOUNTY_STUDIO_TESTS=1 gltest tests/integration/test_localnet_mocked.py -v -s --network localnet`.
5. For real smoke, deploy one local contract and publish its contract/wallet/current-nonce gist marker, owned by the bound numeric GitHub id. Create six zero-value bounties on open issue(s) before merging PRs. Use three for the complete PR and three for the partial PR. Another GitHub id must merge both fresh PRs into the default branch before their deadlines; include the appropriate standalone `Fixes #issue` line in each immutable merge commit. The historical sandbox PRs and address-only gist are obsolete. Set `BOUNTY_LIVE_CONTRACT`, `BOUNTY_COMPLETE_BOUNTY_IDS=0,1,2`, `BOUNTY_PARTIAL_BOUNTY_IDS=3,4,5` (actual distinct ids), and `BOUNTY_COMPLETE_PR` / `BOUNTY_PARTIAL_PR` to the fresh selectors. Run `ISSUE_BOUNTY_STUDIO_TESTS=1 ISSUE_BOUNTY_LIVE_SMOKE=1 gltest tests/integration/test_live_smoke.py -v -s --network localnet`. The key must also be present in the runner environment for prerequisite detection. Both smoke and mocked suites reject non-localnet or non-loopback RPCs before deployment/writes.

Each PR runs once per distinct precreated bounty, preventing duplicate rejected-diff resampling and avoiding historical-merge eligibility bypass. Record consensus status, per-node scores and diff hash in CONSENSUS.md. GitHub requests from a shared IP are limited, so spread out runs. I-4 covers both decision and immutable-reference committee disagreement. Native Sandbox error conversion/isolation must be validated there; the direct adapter cannot establish protocol behavior. I-1 advances local mock transaction time past the seven-day hold; Bradbury testing must wait for actual maturity.
